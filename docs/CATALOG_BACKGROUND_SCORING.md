# 资料库背景评分

资料库中的竞赛、期刊 / 会议和公司条目现在会生成一份独立的背景材料评估，保存到 `.data/resumes/.metadata/material-library.json` 的 `__catalog__` 分区。当前资料库共有 230 条记录：竞赛 122 条、期刊 / 会议 100 条、公司 8 条。

背景评估只读取条目已有的公开简介、领域、赛制、研究渠道说明、来源和组织信息。它复用 v1.3 的材料因素和参数；竞赛条目使用赛事质量分 Q，不生成候选人的获奖表现比例或个人行动证据，因此五个能力维度的个人贡献始终为 `NA`，不会进入候选人岗位排序。

资料不足的因素保持 `NA`，不会用 0 代替未知。当前 230 条条目均有保存的评估记录，其中 164 条形成了数值材料分，66 条因缺少可支持的材料因素保留 `NA`。资料库卡片显示的是“资料库背景”条目，候选人简历关联分仍单独保留。
