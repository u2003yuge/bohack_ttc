# 评分方法 v1.4

本版本在 v1.3 的竞赛两阶段评分基础上调整个人行动归因和材料递减参数。已有简历与资料库分数不会自动被覆盖；重新评估时使用 `material-derived-v1.4.0`。

当一项候选人材料已经产生材料分 `M`，但原文没有足够行动证据证明某个能力维度时，该维度使用最低个人行动系数 `A=0.1`，并标记为暂定。资料库背景条目没有候选人，不使用该最低值，个人能力贡献保持 `NA`。

因此：

```text
D = M × R × A
```

如果 `M=0`，对应维度贡献保留数值 `0`；只有材料分或赛事质量本身未知时才使用 `NA`。这样雷达图可以区分“确定为零”和“证据不足”。

同类型材料递减系数调整为：竞赛 0.45、论文/研究 0.60、项目 0.55、工作/实习 0.70、专利 0.55、开源 0.60、证书/课程 0.45。不同类型仍分别从 1 开始递减。
