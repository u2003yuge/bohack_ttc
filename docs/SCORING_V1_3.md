# 竞赛评分方法 v1.3

本版本只修改竞赛材料的计算方法，不自动重算已有简历或资料库记录。已有记录保留在历史中，新的评分版本为 `material-derived-v1.3.0`。

竞赛先计算赛事质量分 `Q`：

```text
Q = 0.5 × 有效参赛规模分 + 0.5 × 赛制与评审分
```

有效参赛规模分仍使用 `8 × ln(1 + n)`；赛制与评审分使用 45、75、100 三档。奖项层级和官方奖项比例不再直接加到 `Q`。

候选人表现比例为：

```text
P = 选择性系数 × 实际获奖层级系数
M = Q × P
```

选择性系数使用官方公布的目标奖项比例 `p`，计算为：

```text
min(1, -ln(p) / -ln(0.001))
```

参考比例 `0.001` 表示 0.1%。实际获奖层级系数为：最高奖 1.00、一等奖 0.85、二等奖 0.65、三等奖 0.45、明确入围/优胜 0.25。缺少官方比例或实际获奖层级时，`P` 和最终材料分 `M` 保持 `NA`。

得到 `M` 后，后续仍按原流程计算：`D = M × R × A`，再按材料类型递减聚合到候选人的五个能力维度。资料库背景条目没有候选人获奖表现，使用赛事质量分作为背景分，个人能力贡献仍为 `NA`。
