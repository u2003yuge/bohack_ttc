# 简阅项目海报生成上下文

## 使用场景与输出规格

- 用途：TTC“AI 赋能招聘与人才挖掘”赛道项目展示海报
- 画幅：80 cm × 180 cm，竖版，适合展架远距离阅读
- 输出：最终 JPG；建议按印刷精度制作，保留四周安全边距
- 文件命名：`赛道名称-团队名称-项目名称.jpg`
- 推荐暂用文件名：`AI赋能招聘与人才挖掘-简阅团队-简阅.jpg`

## 可直接交给海报生成模型的提示词

请设计一张面向招聘评委、HR 和技术观众的中文项目展板海报，项目名称为“简阅｜简历工作台”。项目属于 TTC“AI 赋能招聘与人才挖掘”方向，核心定位是：一个能自搜索、自积累的简历量化评阅台。海报为 80×180 cm 竖版，信息密度适中，远距离可读，风格克制、理性、可信、现代，体现“证据驱动的 AI 招聘工具”而不是泛泛的 AI 概念海报。

### 必须出现的准确文字

- 主标题：`简阅`
- 副标题：`简历工作台`
- 中文 Slogan：`一个能自搜索、自积累的简历量化评阅台`
- 英文 Slogan：`auto-searching, auto-strengthening, auto-scoring`
- 赛道语境：`AI 赋能招聘与人才挖掘`
- 团队成员：`章壹程｜刘砚桐｜刘思岑`

### 项目介绍文案

`简阅是一款本地运行的 AI 招聘简历阅读与分析工作台。它把 PDF 简历中的经历、成果和个人行动转化为有来源、可解释、可比较的量化评估，帮助招聘者更快看懂候选人，更公平地进行岗位匹配。`

### 核心功能文案

用 4 个连续步骤构成海报主视觉流程，每一步配简洁的界面化图形或数据卡片：

1. `导入简历`：批量导入 PDF，在应用内阅读原始简历
2. `提取证据`：识别奖项、研究、项目、实习、专利、开源、证书等材料，并保留原文依据
3. `量化评阅`：按固定规则计算材料分，将个人行动映射到专业执行、问题解决、责任交付、协作组织、学习研究五维能力
4. `岗位排序`：结合岗位偏好比较候选人，查看排名、历史样本和可追溯证据

### 技术亮点文案

- `React + TypeScript + Vite`：构建简历库、分析工作区和候选人对比
- `Express 本地 API`：负责导入、分析编排、进度与本地数据保存
- `PDF.js`：中文 PDF 阅读、文本提取与证据定位
- `可配置 AI Agent`：提取事实、生成解释，评分函数由代码规则计算
- `可解释评分引擎`：材料分 → 个人行动 → 五维能力 → 岗位排序
- `本地优先与隐私保护`：简历和候选人数据默认保存在运行本项目的电脑上

### 视觉构图

- 顶部约 20%：放置“简阅”主标题、中文 Slogan、英文 Slogan 和赛道标签。标题要有明确品牌识别，不使用夸张科技字体。
- 中部约 55%：以“简历页面 + 证据高亮 + 评分卡 + 五维雷达图 + 排名列表”构成一条由左上向右下推进的工作流。用细线、箭头和编号连接四个核心步骤，表现从原始材料到可解释结论的过程。
- 下部约 20%：使用三列或上下分区呈现“项目介绍 / 技术亮点 / 团队成员”，每块内容短而清晰，避免大段正文。
- 底部约 5%：放置隐私提示 `Local-first · Evidence-based · Explainable` 和团队成员姓名；保留充足留白，不塞满信息。
- 所有信息按阅读优先级排版：项目名 > 中文 Slogan > 解决方案流程 > 核心功能 > 技术亮点 > 团队信息。

### 视觉语言

- 主色：深墨色 `#1F2329`、深蓝 `#2B4365`、品牌蓝 `#3370FF`
- 辅色：蓝灰 `#6A7B92`、浅灰背景 `#F5F7FA`、白色面板 `#FFFFFF`
- 点缀：少量紫蓝 `#7657F6`、证据高亮金 `#FFDC4A`、暖橙 `#DC8164`
- 使用低饱和浅灰背景和白色信息面板，配细边框、轻阴影、细网格、数据条、雷达图和证据标记；整体像可信的招聘分析工作台。
- 蓝色用于流程、链接和评分重点，黄色只用于简历证据高亮，紫色只作少量状态强调；不要做大面积霓虹渐变。
- 字体使用清晰的中文无衬线字体，数字和英文使用现代无衬线字体；保证中文笔画完整、字距舒适、标题和正文层级明显。

### 生成约束

- 竖版展板，不要做成横幅、手机海报或营销落地页。
- 必须保留所有指定文字，文字要逐字准确，不要擅自改写、增删或生成乱码。
- 不要出现真人肖像、招聘办公场景照片、机器人头像、夸张 3D 科技球、霓虹电路背景、赛博朋克风、无意义的装饰性代码。
- 不要使用虚构的合作方 Logo、学校 Logo、奖项 Logo 或无法核验的数据。
- 不要把“AI”做成唯一视觉中心；重点是“简历证据如何被提取、量化、解释和用于岗位排序”。
- 不要把评分表现为不可解释的黑盒总分；视觉上要能看见原文证据、材料分、五维能力和岗位偏好之间的对应关系。
- 文字区域使用可编辑排版或矢量文字层，最终导出前人工校对中文、英文、数字、标点和团队姓名。

## 设计交付检查

1. 画布比例为 80:180，竖版构图，适合展架阅读。
2. 项目介绍、核心功能、技术亮点、团队成员均已出现。
3. `简阅`、中文 Slogan、英文 Slogan 和三位成员姓名无错字。
4. 图形能表达“导入 → 提取 → 量化 → 排序”的闭环。
5. 背景、面板、文字和强调色之间有足够对比度。
6. 最终文件为 JPG，并按 `赛道名称-团队名称-项目名称.jpg` 命名。
