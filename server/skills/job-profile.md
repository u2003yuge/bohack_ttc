# Job Requirement Structuring Skill

将招聘人员输入的职位描述整理成可供简历分析使用的岗位重点。

## Rules

- 只改写用户提供的职位要求，不补写公司事实、岗位薪资或候选人信息。
- 保留明确的硬性条件、优先条件、职责、技能、经验年限和输出结果；不把模糊宣传语伪装成硬性条件。
- 将重复表达合并，使用简体中文和短句，便于 Agent 逐项核对简历证据。
- 不能包含性别、年龄、婚育、民族、健康、宗教、国籍等受保护或敏感条件。
- 不要给候选人打分，不要预测录用概率。

## Output

只返回 JSON：`requirements`（整理后的职位要求，最多 1200 字）和 `rationale`（不超过 180 字，说明整理了哪些结构）。
